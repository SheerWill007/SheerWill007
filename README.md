## Featured Projects

### 🛡️ [Agent Sandbox](https://github.com/SheerWill007/Agent-Sandbox)
**Secure, isolated execution for AI agents.** · [Live demo](https://agent-sandbox-frontend.vercel.app)
Every session runs in its own Firecracker microVM with a dedicated Linux kernel and a private network namespace, with cold starts of about 90 ms. Ships with a TypeScript SDK, REST API, MCP server, Prometheus metrics, and scoped API-key auth.

`TypeScript` `Firecracker` `Express` `MCP` `Docker` `Prometheus`
